# Calendar Date Picker

## Priority: Medium

### Description
Replace the plain `<input type="date">` on the booking page with `react-day-picker` for a richer, more accessible date selection experience.

### Implementation Steps
1. Install `react-day-picker`
2. Replace the date input in `src/app/booking/page.tsx` with DayPicker component
3. Style with Tailwind (react-day-picker is Tailwind-compatible)
4. Disable past dates
5. Optionally highlight popular departure windows

### Dependencies
- `react-day-picker`

### Depends On
- Nothing — can be done independently
